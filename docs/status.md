### AI 모의투자 (가장 중요한 기능)
- **AI 점수** = 상승 확률 45% + 퀀트 35% + 매집 20%, 시장 상태가 나쁘면 주식 비중을 줄이고(100/60/30%) FOMC·주요 발표 전날은 새 매수를 절반으로
- **과거 시뮬레이션**: 1~24개월, 시작 자금 직접 설정. 매일 **그날 종가까지의 데이터만 보고** 판단 → 다음 날 시가에 체결 (미래 데이터를 모르는 상태). 수수료·거래세·슬리피지 포함, 지수와 비교 그래프
- **개선 옵션**(기본 켬): 학습형 가중치(최근 성과로 세 신호 비중 조절) + 추세 필터(50일선 아래는 안 삼). 옵션을 끈 '기본 방식'도 같이 계산해 비교 표
- **중단 버튼**, "database is locked" 저장 실패 수정
- **실시간 모의투자 계좌**(최대 5개): 장 마감 15분 뒤 판단 → 다음 날 개장 1분 뒤 체결, 장중 5분마다 손절·목표가 확인. 실제 돈은 안 씀

### 계정 · 보안
- 회원가입(이메일 또는 휴대폰 6자리 인증), 비밀번호 찾기·변경, 닉네임, 마이페이지(로그인 기록, 모든 기기 로그아웃, CSV 내려받기, 탈퇴)
- 로그인 대입 공격 차단(IP 5번 / 계정 10번 → 15분), 유출 비밀번호 거부(Have I Been Pwned, 비밀번호는 밖으로 안 나감), 처음 보는 IP 로그인 알림 메일
- 2단계 인증 코드 재사용 불가, 브라우저 보안 정책(CSP), 클라우드 앞단 접속 비밀번호(Caddy) + HTTPS
- **이번 작업 (2026-11-25)**
  - **2단계 인증(Google Authenticator) 필수**: 등록하기 전에는 등록 화면만 쓸 수 있고 다른 데이터는 서버가 전부 막음 → 비밀번호를 훔쳐도 내 휴대폰이 없으면 못 들어옴
  - **초대받은 사람만 가입**: 관리자(나)가 마이페이지에서 만든 1회용 초대 코드(3일)가 있어야 가입. 틀린 코드를 계속 넣으면 그 IP 차단
  - **관리자 화면**: 초대 코드 만들기·취소, 회원 목록(2단계 등록 여부·초대한 사람·최근 로그인), 회원 차단(바로 모든 기기에서 끊김). 만들기·차단은 2단계 코드를 한 번 더 확인

## 2. 앞으로 할 일

### ① 사용자가 직접 할 일 (지금 바로)
1. **최신 코드 받기**: `git pull origin claude/dazzling-darwin-et76zj` → 다시 켜기 (서버는 `bash deploy/update.sh`)
2. **로그인하면 나오는 2단계 등록 화면에서 Google Authenticator 등록** — 업데이트 직후 바로 (등록 전에는 비밀번호만으로 들어올 수 있는 틈)
3. 사이드바 맨 아래 **관리자 전용 → 관리자** 페이지가 보이는지 확인 (처음 만든 계정이 관리자). 회원 목록에 모르는 계정이 있으면 **차단**
4. 마이페이지에서 **이메일 인증** + `.env` 메일 설정(SMTP) — 비밀번호 찾기·보안 알림용
5. (선택) **휴대폰 알림**: ntfy 앱에서 stock_app 전용 주제 구독 → `.env` 의 `NTFY_TOPIC` → KIS 모의투자 화면 '알림 시험 보내기' ([kis-mock-trading.md](kis-mock-trading.md) 1-1)
6. **AI 모의투자 실제 데이터 검증**: 과거 시뮬레이션을 국내 2년·1년, 미국 2년·1년으로 돌려서
   - 지수 대비가 대부분 플러스인지 · 최대 낙폭이 지수보다 작은지 · 매도 건수가 50건 이상인지 · 개선 옵션이 기본 방식보다 꾸준히 나은지
   - 결과 화면을 캡처해서 보내 주면 같이 판단
7. 결과가 괜찮으면 **실시간 모의투자 계좌**를 만들어 몇 주 돌려 보기
8. Oracle VM 자리가 나면 서버 설치 (`docs/setup-cloud.md`)

### ② 2단계: KIS 모의투자 연결 — 만들었음, 사용자가 연결해서 확인할 차례
- KIS 모의투자 계좌 신청 + 모의투자용 앱키 발급 → `backend/.env` 에 `KIS_MOCK_APP_KEY`·`KIS_MOCK_APP_SECRET`·`KIS_MOCK_ACCOUNT_NO` → 서버 다시 켜기 ([kis-mock-trading.md](kis-mock-trading.md))
- 처음엔 **1주짜리 주문 하나**로 승인 → 접수 → 체결과 화면 잔고가 KIS 앱과 같은지 확인 (이 개발 환경에선 KIS 서버에 못 붙어 가짜 서버로만 확인함)
- 몇 주 돌려 보고 결과(제안 적중·손익·막힌 이유)를 본 뒤에만 3단계(실제 계좌, 소액)를 검토
- 아직 안 한 것: 미국 주식 모의 주문 (지금은 국내만)

### ③ 3단계 (나중에, 실제 돈) 전에 더 필요한 보안
- 실거래용 KIS 키는 **주문 권한이 있는 키**라 서버가 뚫리면 엉뚱한 매매로 손실이 날 수 있음 (출금은 API 로 안 됨)
  → 실거래는 소액 전용 계좌, 하루 손실 한도, 주문 승인 필수로 시작
- 외부 전문가 보안 점검은 받은 적 없음 — 큰 돈을 넣기 전에 고려
- 2단계 등록 전 틈: 업데이트 직후 바로 등록하기 (위 ①-2)
